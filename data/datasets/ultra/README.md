## 使用边界

- 原始 data.yaml 使用 ../train/images 等相对路径，运行训练或评估前需按实际加载器检查其解析位置；本次没有改写原配置。
- 当前 421/120/61 划分不同于已收录量化精度报告中的 387/125/90 划分，不能直接把 test/ 视为那份 90 图报告的测试集。
- 四个 _mp4 文件名前缀均同时出现在 train、valid、test。此观察基于文件名，不是独立来源审计；不能声称本包已经按视频来源隔离，也不能直接作为无同源泄漏的独立测试集。
- 数据集不包含板端逐图预测，因此没有新增实板 mAP 或重现既有精度报告。
