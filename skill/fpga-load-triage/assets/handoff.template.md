# 加载故障交接模板

1. 版本：板卡/镜像/内核/解释器/PYNQ/运行库/驱动（未知写UNKNOWN）。
2. 运行路线与实际文件：路径、构建ID、哈希、来源；哪些必须同次构建及依据。
3. 最小复现命令：明确终端、工作目录、环境脚本和输入；不要包含密码。
4. 最后成功里程碑：原始日志及时间；第一个未返回/失败调用。
5. 直接观察：文件、日志、波形；区分文件推算与硬件读回。
6. 假设表：假设 / 支持证据 / 反证 / 下一项检查 / 责任人。
7. 若涉及复位：IP的实际极性参数、驱动值、同步时钟、输出波形、综合网表是否与bit同版。
8. 若涉及中断：连接、编号、设备树、驱动与内核日志；不要仅由一条warning定根因。
9. 最小修正与产物要求：工程修改位置、重建流程、同次产物、构建日志、清单。
10. 复测顺序：文件校验→环境→加载返回→硬件标识→执行→黄金比对→系统测试。
11. 停止条件：加载已知挂住时不重复尝试；未知项不填通过；记录重启前后状态。
