# 版本演进

最终硬件基线为V0.17。后续V0.17.3、IIC修复及模型切换使用相同bit、hwh、xclbin和XSA，四项SHA256均一致。软件版本变化不应自动解释为Overlay重新实现。

|V0.5|Letterbox将640×480转换为640×640三通道，补边114|PS不得重复补边或重复归一化|

## 修改边界

复位极性、顶层引脚、调度逻辑和DPU硬件配置变化，需要修改RTL/BD并重新生成配套硬件。运行环境、CPU后处理、IIC事务策略、输入线程及服务配置变化属于软件或系统配置。

仅更新兼容模型通常不需要重新布局布线，但必须完成模型编译和后处理适配。文件身份检查只能证明版本一致，不证明时序、外设和持续运行均通过。
