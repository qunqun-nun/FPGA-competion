# 案例来源与已验证边界

案例属于2026-11-02至03的ZCU104项目历史协作，非本次编写skill时重跑板卡。通用技能可以换题/板复用；下列硬件专用常量不可直接跨板使用。工程证据在原工程support目录，摘要和一组可复算任务数据随本技能交付。

## C1 启动镜像与预留内存
默认image.ub缺少项目no-map，root检查拒绝运行；临时启动已验证image17.ub后通过。后续在读懂原boot.scr读取uEnv逻辑、备份后配置fitimage_name=image17.ub，实现无人干预重启与脱离电脑冷启动，用户确认有图。未覆盖BOOT.BIN或原image.ub。镜像SHA：85e95b12459440348cb43c20c2b202b01be513b8df704ec1a85681e9da240902。

本项目三缓冲0x20000000+0x004b0000，输入0x21000000+0x00200000；仅用于解释失败来源。换板/换工程依据真实地址、设备树和驱动策略重新核实。

## C2 HDMI/IIC和时钟
本板输出DP159为0x5e，0x5c为输入TMDS181，不向其写输出配置。IDT 0x6c在工厂或已知配置态用两次完整读取与配置证据验证，不能仅凭FF ID判断失败。修复加载/Runner后FCLK0回到150MHz的问题后，寄存器推算99.999MHz。此为PYNQ寄存器推算，不是示波器测量。

三次历史启动出现IDT短传输；修复为仅在工程核准的空闲/无仲裁冲突/FIFO安全条件下有限重试完整只读事务，39个配置字节分7块比较。故障注入与实板15项测试通过；修复后的实际测试无IIC重试发生，不能声称在实板故障现场恢复。电气根因未确定。

HDMI_INIT_OK不等于STREAM_UP或可见画面。曾因显示器未开机、测试已结束门控造成观察不一致。OSD实现只有框，没有文字接口，缺字不是证明字体模块故障。

来源：support/model50_iic_fix_20261102 的修复报告/原始证据；support/v0173_board_20261102 的原版证据。

## C3 新模型必须配套CPU头
旧INT8交付SHA 64fde5e0f8f21c1d42c253e29db2104c31b6b226a40b2269d3fba40b33b3b5e3，后续分视频训练新模型SHA 765a836d815ef8c9ebf6bcfb1811303768ba7d518cee3679b2c59a1eee989922。两者均以DPU中间特征输出，六路CPU末层不可复用旧权重。输入FP7，后者cv3 FP4/4/4有别于前者5/4/4，输出名也改变。

后者实际DPU指纹属性dpu_fingerprint=0x101000016010407；最初脚本误用fingerprint在下载前失败，修正后通过。三次DPU真实推理、60帧摄像头链通过，用户确认有实时画面。切换持久入口后一次桥失锁，显示器未开机在时间上相符但因果未证；重新启动后运行。不能据旧测试图空预测推断精度失败或成功，也不能将甲的NNDCT仿真mAP视作XModel实板mAP。

来源：support/grouped_model_20261103/新训练集模型_DPU部署记录_20261103.md及其board_evidence.tar.gz。

## C4 开机服务环境和隐含依赖
手动终端正常，systemd第一次失败No Devices，补齐XILINX_XRT=/usr解决环境缺失。禁用Jupyter后仍被clear_pl_statefile.service的Requires拉起，默认boot.py还会加载BaseOverlay；记录原状态、按独占需求停用相关服务后正常自动出图。换题不要默认mask相同名称服务，先读本机依赖。

来源：support/model50_iic_fix_20261102/autostart/独立启动配置与回退说明.md、串口重启日志。

## C5 可复算性能案例
随包evidence/historical_tasks.jsonl来自上述旧模型（64fde5…）的真实任务记录，仅正规化字段而未改时间与耗时。source哈希、映射和归属在provenance.json。

预热10次，正式120次，83.9340675秒。摄像头成功read约20.8735 FPS，整机检测1.42969 FPS，完整检测调用平均290.2594ms、P95 304.25513ms，CPU末层平均227.8313ms，DPU平均13.9955ms。无检出目标，跟踪状态始终0；有效定位性能/mAP/显示延迟未测。PL丢帧计数0不代表相机到应用无丢弃。

这些数据只属于旧模型和当时配置，不能作为新模型或其他板卡指标。瓶颈观察：CPU末层占检测调用大部分；没有在本技能中宣称完成性能优化。脚本可复算：

```sh
python scripts/evidence.py stats references/evidence/historical_tasks.jsonl NEW_SUMMARY.json
```
