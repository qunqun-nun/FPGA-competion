# 可直接使用的提示词

## 修改 IP

使用 fpga-ip-verify-deliver。先核对这个 XPR 实际引用和接口，建立可回退快照。按当前版本查官方文档/例程和相关原作者开源测试，记录具体采用方法。为本次修改写独立黄金参考、自检 TB、协议断言与超时，覆盖正常、边界、背压、复位、异常恢复。给出阶段结果和证据，不把语法通过当功能正确。既有审批范围内持续推进，进入主工程如需我明确批准则遵循原约定。

## 修复故障

先复现原失败，分清观察、假设和未知。寻找已验证正常实现，只改变一个可解释因素；用能暴露原故障的测试证明修复，再回归邻接链。连续失败时回到假设与架构，不叠加猜测补丁。不把降级 DRC 或改元数据当根因修复。

## 整套交付

按当前 PYNQ/XRT 路线准备配套硬件、可编辑工程、软件/模型/初始化/依赖、测试输入与验证证据，生成角色清单及 build_record。先 audit 后 pack，再换目录和干净启动验收。下一位应能按说明运行，不依赖我的个人路径。无板卡实测时 stage=board_retest，列出接收者待测，不伪称 accepted。
