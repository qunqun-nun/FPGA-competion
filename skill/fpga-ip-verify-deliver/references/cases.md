# 来源与失败经验

来源为用户本项目协作过程及提供的交接需求，本文件提炼规则，不新增本次硬件实测结论。

|观察/失败|提炼的方法|不可直接外推|
|---|---|---|
|写完 RTL 仍可能握手错误、仿真看波形难判断|每次配自检 TB/scoreboard，注入背压与错误确认检测器有效|仿真通过不等于 CDC/布局布线/实板通过|
|封装 IP 与主工程实际引用不一致|核对真正 XPR/IP 文件集，封装后检查 component.xml、升级实例并 BD 验证|不根据文件名相同认定源码相同|
|只拿到固定 XSA，缺可链接平台/XO/link 配置|按运行路线交付完整构建输入与日志|普通 PYNQ 不要求 DPU XO 或 xclbin|
|aux_reset_in 极性与常量组合使 AXI 始终复位|核对实际参数/连接，必要时网表仿真重现并回归|不能规定所有工程都接同一个常量|
|加载后 FCLK0 与设计不一致|对照 PS/启动/加载后运行状态，不仅改 HWH|频率按当前工程契约，100MHz 不是通用默认|
|有 HDMI IP 但黑屏，TX/RX 器件地址与已配置状态误判|交付初始化软件，区分身份/配置态，分层验收至实际画面|器件地址/ID 判断与重试条件不能跨板复制|
|只交 Overlay，下游仍缺 CPU 后处理、传帧或系统依赖|启用特性清单，完整软件和依赖与硬件配套|同名 xmodel 不保证 CPU 参数相同|
|只给生成脚本，接收者无法直接打开真实工程|交付实际可打开 XPR及依赖，并换目录验证|有 XPR 不等于无绝对路径或许可证依赖|

本包编写时查看的官方/原作者入口在 reference-research.md，参考组织方法来自用户补充的 Skill 写法：阶段门控、渐进加载、优先级、反例和可验证输出。没有使用附件中的 Star 数作为技术选择依据，未复制那些 Skill 的完整内容或许可证。
