## 三、怎么查

- 01_运行日志：最新模型真实推理报告、camera.log/exitcode、service.log、测试命令及原始串口；历史修复版运行/重启程序日志分别存放。
- 02_FPS：对照CSV、最新模型90秒与12秒原始观测；历史120次正式任务、逐任务CSV、capture时戳、汇总与采集/复算脚本。
- 03_精度：指标CSV及甲的原始交付，不含伪造标注或实板准确率。
- 04_重启复测：实际U-Boot启动、服务配置/变更、Power down、后续用户反馈；早期冷启动失败保留供对照。
- 来源索引.json：每个复制文件在原工程的位置、包内位置与SHA256。
- SHA256SUMS.json：所有交付文件校验；不包含清单自身。

原文件可能写“待现场确认”，这是记录生成时的状态；后续用户确认单独补充在04目录。板端系统时钟为2022年，命令主机时间属于2026年，不能仅用板端日期排序不同测试。

本包原始日志保留历史失败和清理过程。测试结束前台程序正常退出会门控HDMI；服务active、STREAM_UP、目视有图分别看对应证据。无精度真值/独立跟踪计数/显示录像的项目如实未测。
